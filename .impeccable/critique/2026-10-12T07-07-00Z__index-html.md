## Priority Issues

- **[P0] สถานะอัปโหลดล้มเหลวเป็น toast ที่หายไป** — uploadButton.onclick ตอนล้มเหลวซ่อน spinner แล้ว showMessage("Upload failed (N) - press Upload again","error") 3.5 วิ

- **[P1] Modal ไม่ใช่ dialog** — .modal-overlay ไม่มี role="dialog", aria-modal, ชื่อหัวข้อ, ไม่ย้าย focus เข้า (focus อยู่ที่ BODY ทั้ง #reportModal และ #passwordModal), ไม่มี focus trap, ไม่มี Esc, พื้นหลังยัง tab ถึง
  - **Why it matters**: ผู้ใช้คีย์บอร์ด/screen reader หลุดออกนอกหน้าต่างได้ และทุกคนปิดด้วย Esc ไม่ได้
  - **Fix**: เปลี่ยนเป็น <dialog> + showModal() (ได้ focus trap, Esc, พื้นหลัง inert ฟรี), aria-labelledby ชี้ .lt-modal-title, คืน focus ให้ปุ่มที่เปิด
  - **Suggested command**: /impeccable harden

- **[P1] ไม่มีคำบอกใบ้สำหรับท่าหลัก "แตะแผนที่"** — HUD โชว์ --.------ ตารางว่างไม่มี empty state

  - **Fix**: เมื่อ currentLat===null แสดงบรรทัดเดียวตรงที่ #address-display จะโผล่ ("แตะแผนที่ หรือกด ⌖ เพื่อระบุตำแหน่ง") และปิดปุ่ม UPLOAD/Save จนกว่าจะมีหมุด พร้อม empty state ของตาราง
  - **Suggested command**: /impeccable onboard

- **[P2] 745 หมุดไม่ cluster + 745 แถวในตาราง** — renderTable() วาดทุกหมุดและทุกแถว แผนที่ DOW เป็นก้อนเดียว รายการเป็น scroller 320px หลายร้อยแถว

- **[P2] ลำดับความสำคัญของปุ่มและ feedback** — .lt-save ใหญ่เกือบเท่า .lt-primary; toast ชนิด warning ใช้ไอคอน info สีฟ้า; หมุดที่เลือกกับหมุดรอส่งสีเทาเหมือนกัน; Find (#searchLocationButton) และ Export CSV (.lt-text-btn) contrast 4.0:1 ไม่ผ่าน AA
  - **Why it matters**: คำเตือน "นอกพื้นที่" ดูเหมือนข้อมูลธรรมดา; ปุ่มรองแย่งความสนใจจากปุ่มหลัก; ตัวอักษรบางส่วนอ่านยากกลางแดด
  - **Fix**: ลด Save เป็นปุ่ม ghost/ข้อความ; เพิ่ม branch warning (ไอคอนสามเหลี่ยมสีเหลืองอำพัน) ใน showMessage; หมุดที่เลือกใช้สีฟ้าหลัก; Find และ Export CSV ใช้ --primary-hover

- **[P3] ภาษาและ micro-copy** — UI อังกฤษให้พนักงานไทย ปุ่ม Google เป็นไทย ที่อยู่เป็นไทย html lang="en"
  - **Fix**: หน้าภาคสนามเป็นไทยโดยค่าเริ่มต้น (admin คงอังกฤษได้) และแก้ข้อความ: "Unlock Console" → "Admin sign-in", "Recent Sessions" → "Records", "GPS Failure" → "หาตำแหน่งไม่ได้ — ตรวจสิทธิ์ Location", "Confirm New Sequence" → "Save order"
